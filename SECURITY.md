# Seguridad

Esta es una herramienta preliminar. No adjuntes reportes privados ni archivos de volcado de memoria a incidencias públicas.
Para reportar problemas de seguridad, crea un issue privado o contacta al responsable del repositorio mediante un canal privado configurado por él.
La actualización de software debe realizarse solo tras copia de seguridad, comprobación de dependencias y aprobación explícita.
